# EU Reform Vision — current plan

## Current focus

Build the information architecture and working system before expanding the volume of content.

## Phase 1 — make the project navigable

- Establish `/book/...` as the public canonical route and retain `/docs/...` only as a legacy compatibility layer.
- Make the European English proposal reachable from the homepage within two clicks.
- Define the internal `ue_internal` and `plan_ue_internal` surfaces without exposing planning material in the public menu.
- Add a repeatable public-document/sidecar pattern.

## Phase 2 — define each pillar

For each pillar create:

1. a public charter explaining the problem and promise;
2. a research sidecar preserving hypotheses and evidence gaps;
3. one or more implementation documents;
4. a follow-up list containing decisions, experiments and recruitment needs.

## Phase 3 — deepen the content

- European English: charter, 60-item pilot method and administrative implementation;
- Digital integration: European software institution, reusable public software and voluntary adoption blocs;
- Robotic reindustrialisation: dual-use research frame, agricultural automation and defence-related questions;
- Benefits: citizens, businesses, regions and institutions.

## Working rule

Do not scale content production until the purpose, hierarchy, canonical routes and task system are clear. Each large idea becomes an epic; each epic is split into bounded tasks with acceptance criteria and a test or review plan.
