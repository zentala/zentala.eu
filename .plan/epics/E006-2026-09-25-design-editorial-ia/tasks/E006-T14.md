## Steps

1. §8.1: page title and h1 "Site Map"; columns Start here / The frame / Floor / Middle / Ceiling / How we get there / Reference exactly as the table says; each line title + small `kind` label; drafts filtered like `/book`; "Unsorted" shown when non-empty; columns collapse to one at phone width.
2. §8.2: inline SVG produced at build from `src/data/link-graph.json`: columns = layers in frame order + Pages + Reference; nodes ordered by `order`; node fill by layer colour (DESIGN.md tokens), border style by `kind` (solid / dashed / double), size by inbound count in three steps; curved edges with arrowheads; hover/focus highlight through CSS `:has()` only; each node an `<a>`. Preview builds (`IS_PREVIEW`) draw dead links and orphans in the warning colour with a legend line. Deterministic layout.
3. Accessibility fallback: `<figure aria-hidden="true">` + `<figcaption>`; a `<details>` "Connections as text" listing "links to: …" per chapter from the same JSON.
4. `scripts/content-audit.mjs` gains, with counts and `path:line` in the report: (a) two-click depth from `/` for every published page; (b) `layer` and `kind` present on every published `book/*` entry, `kind` on `why`/`manifesto`; (c) every glossary `href` resolves to an existing id in the built HTML; (d) no `/docs/` link in any chapter, `/why`, `/manifesto`; (e) no built HTML links a path in the `astro.config.mjs` redirect table; (f) a chapter that declares a concept links its canonical `href` (glossary) somewhere in its body or footer. Zero processed files = failure.
5. `just build`; `just audit`; Playwright screenshots (`chromium.launch({ channel: 'chrome' })`) of `/site-map/` in both themes to `.plan/reports/2026-09-25-e006/T14-*.png` in the main checkout.
