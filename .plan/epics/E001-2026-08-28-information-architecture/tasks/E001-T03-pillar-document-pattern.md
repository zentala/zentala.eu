# E001-T03: Establish the pillar document pattern

## Objective

Make every large proposal expandable through a consistent set of public documents and adjacent draft sidecars.

## Acceptance criteria

- [ ] Define public charter, research sidecar, implementation document and follow-ups.
- [ ] Use `<topic>.sidecar.mdx` for unpublished supporting material.
- [ ] Add a visible “Further work” section to public documents when appropriate.
- [ ] Document when material is promoted from a sidecar.
